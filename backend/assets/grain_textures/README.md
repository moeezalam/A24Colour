# Grain Texture Files

This directory should contain grain texture images:

- `16mm_grain.png` - Coarse 16mm film grain texture
- `35mm_grain.png` - Medium 35mm film grain texture  
- `digital_grain.png` - Fine digital grain texture

## Note

The current implementation generates procedural grain textures as placeholders. For production use, you would need:

1. High-resolution grain texture images (512x512 or larger)
2. Scanned from actual film stock
3. Grayscale PNG format
4. Seamlessly tileable patterns

## Creating Grain Textures

You can create grain textures by:
1. Scanning actual film negatives
2. Using film emulation software
3. Photographing film grain under magnification
4. Using procedural noise generation tools
